# team_CNPM / AITasker

Source gốc được giữ nguyên. Phần đã bổ sung nằm chủ yếu trong:

- `tasker-ui/store/app-store.tsx`
- `tasker-ui/components/aitasker/workflows.tsx`
- `tasker-ui/components/aitasker/landing.tsx`
- `tasker-ui/components/aitasker/role-layout.tsx`
- `tasker-ui/services/fetch.ts`
- `tasker-backend/src/*`

Chạy frontend:

```bash
cd tasker-ui
npm install --legacy-peer-deps
npm run dev
```
